# Roadmap

## v0.1
- plug-in loads in Acrobat Pro
- builds on Windows 11 and macOS (64-bit)
- menu appears
- 2-up planning model
- active document page counting

## v0.2
- create output PDF from active document
- simple 2-up composition
- page padding to even count
- rotate / scale / center metadata in planner (Acrobat composition hookup pending)

## v0.3
- booklet mode
- signatures divisible by 4
- reverse order
- blank insertion rules

## v0.4
- step & repeat
- N-up presets
- crop / trim marks
- page numbering

## v0.5
- bleed and overlap
- simple creep
- PDF overlay support
- XML command history

## v0.6
- CSV variable data
- manual layout editor
- inspector / reverse mapping
