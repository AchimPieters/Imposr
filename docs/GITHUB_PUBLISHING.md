# Publish to GitHub

## Recommended new repository

`AchimPieters/acrobat-imposition-plugin`

## Quick publish steps

```bash
git init
git add .
git commit -m "Initial Acrobat imposition plugin skeleton"
git branch -M main
git remote add origin git@github.com:AchimPieters/acrobat-imposition-plugin.git
git push -u origin main
```

## Suggested first release title

`v0.1.0-alpha`

## Suggested description

Starter repository for an Adobe Acrobat Pro plug-in focused on PDF imposition, booklet creation, N-up layouts, and print-production workflows.
