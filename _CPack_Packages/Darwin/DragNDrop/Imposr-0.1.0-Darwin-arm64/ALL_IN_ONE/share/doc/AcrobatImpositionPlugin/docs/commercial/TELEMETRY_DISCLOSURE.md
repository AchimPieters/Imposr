# Telemetry Disclosure

Transparantiebeleid voor product-telemetry en crash-reporting.

## Vereiste disclosure

- Overzicht van verzonden events en velden
- Expliciete lijst van niet-verzonden gevoelige data
- Opt-in/opt-out gedrag en default instelling
- Retentieperiode en verwijderbeleid
- Telemetry endpoint(s) en regio

## Operationele controles

- Nieuwe telemetry-events vereisen changelog-entry en product review.
- Ongeautoriseerde velden (PII/secrets) zijn release-blocking.
- Telemetry disclosure moet synchroon blijven met werkelijke payloads.

## Governance status

**Status (2026-04-20):** disclosure policy vastgesteld; technische + juridische review vereist per release.
