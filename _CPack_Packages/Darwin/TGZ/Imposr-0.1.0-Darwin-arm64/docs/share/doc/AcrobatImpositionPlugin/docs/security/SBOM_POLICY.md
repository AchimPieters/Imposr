# SBOM Policy

## Policy

- Voor elke release wordt een SBOM artifact gegenereerd.
- SBOM wordt samen met release artifacts opgeslagen en geversioneerd.
- SBOM is verplicht input voor security review en compliance audit.

## Operationele eis

- Release is geblokkeerd als SBOM ontbreekt of niet reproduceerbaar is.
- SBOM tooling-versie wordt vastgelegd in release notes.

## Governance status

**Status (2026-04-20):** SBOM policy vastgesteld en opgenomen in security release gates.
