# Security Release Checklist

Verplichte security gates per commerciële release:

1. Binaries ondertekend (platform-conform)
2. Vulnerability scan uitgevoerd op build artifacts
3. SBOM gegenereerd en als release artifact opgeslagen
4. High/Critical CVEs opgelost of expliciet geaccepteerd met risico-afweging
5. Distributiekanaal en artifact integrity gecontroleerd

## Governance status

**Status (2026-04-20):** security checklist gedefinieerd als harde release gate.
